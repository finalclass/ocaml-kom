# Kontrola architektury

Podział odpowiedzialności określa [architektura](../contracts/README.md).
Publiczne i prywatne moduły są rozdzielone w Dune; scenariusze wykonania
oraz katalogu określa [STP](stp.md).

Automatyczny profil Szańca oparty na kontraktach Cyrograf nie jest
dowodem zgodności natywnych kontraktów Kom. Nie należy raportować
zakończenia build/test jako pozytywnego wyniku analizy Szańca.
